Kebijakan Privasi OtoBuzz

Aplikasi Pencatat Perawatan Kendaraan untuk Pemilik Armada Kecil

1. Pendahuluan

OtoBuzz adalah aplikasi pencatat perawatan kendaraan yang dirancang untuk pemilik armada kecil di Indonesia. Kami sangat menghargai privasi Anda. Kebijakan privasi ini menjelaskan bagaimana aplikasi kami menangani data Anda.

2. Data yang Disimpan

Semua data yang Anda masukkan ke dalam OtoBuzz disimpan secara lokal di perangkat Anda. Data tersebut meliputi:

  • Informasi kendaraan (nama, jenis, plat nomor, dll.)
  • Catatan perawatan dan servis
  • Jadwal pengingat perawatan
  • Foto kendaraan atau dokumen terkait

3. Tidak Ada Server atau Pengumpulan Data

OtoBuzz tidak mengirim data apapun ke server eksternal. Aplikasi ini beroperasi sepenuhnya secara offline. Kami tidak mengumpulkan, menyimpan, atau memproses data Anda di server manapun.

4. Tidak Ada Pelacakan (Tracking)

Aplikasi ini tidak menggunakan layanan analitik, pelacakan, atau iklan apapun. Kami tidak melacak aktivitas Anda, lokasi, atau penggunaan aplikasi.

5. Izin yang Digunakan

OtoBuzz memerlukan izin berikut untuk berfungsi dengan baik:

  • Notifikasi — Untuk mengirimkan pengingat jadwal perawatan kendaraan yang telah Anda atur.
  • Penyimpanan — Untuk menyimpan dan membaca data aplikasi, backup, serta foto kendaraan di perangkat Anda.
  • Kamera — Untuk mengambil foto kendaraan atau dokumen terkait perawatan.

6. Backup dan Ekspor Data

Fitur backup dan ekspor data sepenuhnya dikendalikan oleh Anda. File backup disimpan di perangkat Anda dan hanya dibagikan jika Anda secara eksplisit memilih untuk membagikannya melalui fitur berbagi perangkat.

7. Keamanan Data

Karena semua data disimpan secara lokal di perangkat Anda, keamanan data bergantung pada keamanan perangkat Anda sendiri. Kami menyarankan untuk menggunakan kunci layar dan menjaga perangkat Anda tetap aman.

8. Perubahan Kebijakan

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Perubahan akan ditampilkan di halaman ini dengan tanggal pembaruan yang baru.
